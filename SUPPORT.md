# Support

This repository does not provide production support, integration consulting,
deployment review, legal advice, incident response, or a response-time
agreement.

## Where to ask

| Need | Channel |
| --- | --- |
| Counterexample, proof, locale, or assumption concern | Proof-review issue form |
| Documentation, citation, or rendering defect | Documentation issue form |
| Sensitive vulnerability | Private path in `SECURITY.md` |
| Isabelle reproduction question | Issue with exact commit, tool versions, AFP revision, and command |

Search existing issues first. The maintainer may redirect, close, or leave
unanswered requests outside the scholarly artifact's scope.

## Out of scope

The maintainer cannot certify an implementation or deployment, establish
model-to-code refinement from an issue report, recover assets, operate a
network, determine legal compliance, or provide confidential production
debugging through a public channel.
